# OverChart.ai — public site (draft)

Single-file static site (`index.html`) for the OverChart prototype:
clinic-audio capture → transcription → speaker-labeled transcripts →
optional clinician-review scoring.

- Claims on the page are measured on the PriMock57 mock-consultation
  corpus (CC BY 4.0) — see docs/SPEC.md in the pipeline repo
  (`~/projects/consult-qa`) for the measurement record.
- No patient data anywhere; demo transcript is public mock material.
- Contact line intentionally has no email/phone yet — add before sharing.
